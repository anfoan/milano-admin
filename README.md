# Milano Admin

لوحة التحكم المستقلة لمتجر Milano، تستخدم نفس Firebase الخاص بالمتجر حتى تظهر المنتجات والطلبات والرسائل فوراً في النظامين.

## التشغيل المحلي

```bash
npm install --legacy-peer-deps
npm run dev
```

افتح `/` لتسجيل الدخول، وبعد نجاح الدخول يتم الانتقال تلقائياً إلى مسار لوحة التحكم المحمي.

## النشر على Netlify

- **Base directory:** اتركه فارغاً عند استخدام هذا المستودع.
- **Build command:** `npm run build`
- **Publish directory:** `dist`

يجب عدم مشاركة رابط هذا الموقع مع العملاء. الوصول محمي بتسجيل دخول Firebase وصلاحيات المشرفين، مع دعم حسابات موظفي نقطة البيع.
